# Maw3id

Plateforme SaaS multi-organisations de prise et de gestion de rendez-vous, en français et en arabe.

Toutes les informations du projet (contexte, rôles, structure, exceptions aux règles) sont dans [README-projet.md](README-projet.md). Les règles communes sont dans `.agents/rules/`.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000. La galerie des composants est sur `/fr/systeme-de-design`.

## Commandes

- `npm run dev` : serveur de développement
- `npm run build` : build de production
- `npm run lint` : ESLint
- `npm test` : tests Vitest
